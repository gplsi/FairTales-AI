Supplementary material

A multilingual and multidomain framework for measuring gender bias in large language models

This repository contains the figures and data used for the analysis. The paper method generates narratives with neutral instructions, first annotates references to people through the gender annotation protocol, and then computes the metrics by model, language, topic, and subtopic.

Output organization Figure gallery Annotated data folders

How the outputs are organized

The run directory is runs-FairTales AI/. The visual inspection figures are stored in runs-FairTales AI/figures/. The generated narratives used in the study are available in an anonymized HuggingFace Dataset, and the code used to compute the evaluation metrics is also provided in a separate anonymized repository to support reproducibility. The annotated data lives in model-specific folders following the <model>_databias_generated pattern, and each folder is divided into english, spanish, and valencian.

The paper's method section defines a two-stage workflow. First, the generated narratives are annotated with the gender annotation protocol, which identifies nouns and pronouns referring to people and assigns them a semantic M, F, or N label. The metrics are then computed from those annotations for each model, language, topic, and subtopic partition.

Within each language, numeric directories represent the experiment topic and subtopic. For example, a path such as runs-FairTales AI/Qwen3-8B_databias_generated/spanish/12.0/12.1/ points to a specific Spanish subtopic for the Qwen3-8B model. Those folders contain score files, aggregations, and filtered variants produced by the metric calculation described in the paper.

This page is only an index and explanation layer. It links to the figures and folders included in the repository, but it does not read, compute, or alter any JSON, CSV, PNG, or annotated file.

Figure gallery

The figures visualize metric results after gender annotation. Use the filters to focus the gallery by model or language. The filters only show or hide images already present on the page; they do not inspect the data files.

Heatmaps by model and language

Each heatmap shows the subtopics within each topic for one model and one language. The cells summarize the majority counter from the annotated outputs and make it easier to compare neutral behavior with stereotypical and couterstereotypical behavior across the topic and subtopic hierarchy.

Model summary by language

These figures aggregate log score behavior to compare models within a single language. They show whether a model keeps the same bias pattern in English, Spanish, or Valencian, or whether the pattern changes with the generation language.

Summary by topic

These views organize results by topic. In the paper method, each topic groups four subtopics, and metrics can be computed at the subtopic level, at the topic level by aggregating subtopics, and at the global level. These figures therefore connect the visual patterns back to the numeric output folders.

Annotated data folders

Annotated outputs are grouped first by model and then by language. Within each language, numeric topics and subtopics appear in the form runs-FairTales AI/<model>_databias_generated/<language>/<topic>/<subtopic>/. The all folders are aggregate-level folders inside a topic.

According to the paper's gender annotation protocol, the data files come from identifying terms that refer to people and labeling them as M male, F female, or N neutral when the use is generic, mixed, or ambiguous. From those annotations, metrics such as representation score, count disparity, and log score are computed for each partition.

Quick file guide

  • .scores.json: scores derived from the subtopic annotations.
  • .scores-with-confidence.json: a score version with confidence information.
  • .scores-filtered.json: filtered scores before aggregation outputs are produced.
  • aggregation.csv: the main aggregation of terms, labels, and metrics for that partition.
  • aggregation-disparity-filtered-(0.5).csv: an aggregation filtered by the disparity condition indicated in the filename.
  • aggregation-z2filtered.csv: an additional filtered aggregation variant; the filename preserves the criterion used by the process.
  • aggregation-disparity-filtered-(0.5)-filtered-by-ADJ.csv and filtered-by-VERB.csv: views filtered by part of speech to inspect adjectives or verbs.
